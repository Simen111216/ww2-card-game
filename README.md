# 二战卡牌风云 (WW2 Card Game)

🔗 **在线游玩**: [https://ww2-card-game.vercel.app](https://ww2-card-game.vercel.app)

## 简介
《二战卡牌风云》是一款以第二次世界大战为背景的网页端策略卡牌游戏。玩家可以扮演苏联、德国、美国、英国或法国的指挥官，通过部署历史著名部队、使用战术指令卡来与 AI 或好友进行对战。

## 核心特色
- **五大阵营**: 苏联、德国、美国、英国、法国，各自拥有独特的史实单位和战术指令。
- **三线战场**: 包含己方支援战线、前线交火区和敌方支援战线，考验玩家的排兵布阵与射程把控。
- **史实词条**: 闪击、守护、重甲、伏击等词条，高度还原兵种特色。
- **联机对战**: 支持基于 WebRTC 的纯前端 P2P 联机，输入房间码即可与好友随时开战。
- **震撼视效**: 屏幕震动、指令爆闪、火炮洗地，带来极强的战争压迫感。
- **历史军校**: 答题解锁高级隐藏王牌（如虎王重型坦克、曼哈顿计划等），寓教于乐。

## 本地运行指南
确保你的电脑安装了 [Node.js](https://nodejs.org/)。

```bash
# 1. 进入前端目录
cd web-client

# 2. 安装依赖
npm install

# 3. 启动本地开发服务
npm run dev
```
